# 🐍 Python Practice Programs

A collection of beginner Python programs and Jupyter notebooks from my programming coursework — small, focused exercises covering Python fundamentals: input/output, conditionals, loops, arithmetic logic, and mini-projects like a student marks calculator and a simple calculator.

## 📂 Contents

### Python scripts (`.py`)

| File | What it does |
|---|---|
| `program3.py` | Student marks & percentage calculator (name, USN, 3 subjects) |
| `program10.py` | Checks whether a number is positive/negative and even/odd |
| `program4.py` – `program9.py` | Core Python practice exercises — conditionals, loops and basic logic |

### Jupyter notebooks (`.ipynb`)

| Notebook | Topic |
|---|---|
| `simple calculator .ipynb` | A simple calculator |
| `pp project.ipynb`, `python_project.ipynb`, `python_project 2.ipynb`, `python_project (1).ipynb` | Mini-project notebooks |
| `pg6.ipynb`, `pg7.ipynb`, `prg15.ipynb`, `prg16.ipynb` | Lab program exercises |
| `program 3.ipynb`, `program 4.ipynb`, `pyth2.ipynb`, `pythonprogram.ipynb` | Practice programs |

## ▶️ How to Run

```bash
# Any script
python program3.py

# Notebooks — open in Jupyter or VS Code
jupyter notebook
```
